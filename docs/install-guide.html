설치 가이드

Windows에서 ORDERMASTER 설치 시 보안 경고를 해결하는 방법입니다.

⚠ 왜 보안 경고가 뜨나요?

ORDERMASTER는 안전하지만, Windows는 새로운 프로그램에 대해 자동으로 경고를 표시합니다. 다운로드 수가 누적되면 경고가 자동으로 사라집니다. 아래 방법으로 안전하게 설치하실 수 있습니다.

1 SmartScreen 경고 통과 방법

"Windows의 PC 보호" 화면이 뜬 경우

설치 파일 실행 시 아래와 같은 파란색 화면이 나타납니다.

! Windows의 PC 보호

Microsoft Defender SmartScreen에서 인식할 수 없는 앱의 시작을 차단했습니다. 이 앱을 실행하면 PC가 위험에 노출될 수 있습니다.

추가 정보

해결 방법:

  1. "추가 정보" 텍스트를 클릭합니다.
  2. 창이 확장되면서 "실행" 버튼이 나타납니다.
  3. "실행" 버튼을 클릭합니다.
💡 팁: 한 번만 실행하면 다음부터는 경고가 뜨지 않습니다.

2 다운로드 시 차단 해제하기 (권장)

설치 전에 미리 경고 제거

다운로드한 설치 파일에서 미리 차단을 해제하면 SmartScreen 경고가 뜨지 않습니다.

  1. 다운로드한 ORDERMASTER_Install.exe 파일을 우클릭합니다.
  2. 메뉴에서 "속성"을 선택합니다.
  3. 창 하단에 "차단 해제" 체크박스가 보이면 체크합니다.
  4. "확인"을 클릭합니다.
  5. 이제 파일을 실행해도 경고가 뜨지 않습니다.
💡 차단 해제 체크박스가 안 보이는 경우: 이미 안전한 파일로 인식된 것입니다. 그냥 실행하시면 됩니다.

3 Windows Defender 알림 처리

"바이러스 위협 발견" 알림이 뜬 경우

매우 드물게 Windows Defender가 잘못된 알림을 표시할 수 있습니다.

  1. 알림 클릭 또는 Windows 보안 앱 실행
  2. 바이러스 및 위협 방지 → 보호 기록
  3. ORDERMASTER 항목 클릭
  4. 작업 → "허용" 선택
💡 안전합니다: ORDERMASTER는 PyInstaller로 패키징된 정상 프로그램입니다. 일부 백신이 PyInstaller 빌드를 의심하는 경우가 있지만 실제 위협은 아닙니다.

자주 묻는 질문

왜 "알 수 없는 게시자"라고 나오나요?

현재 ORDERMASTER는 신규 출시 프로그램으로 코드 서명 인증서 발급 절차를 진행 중입니다. 인증서 적용 후에는 게시자가 "AUTOMASTER"로 정상 표시됩니다. 프로그램 자체는 안전합니다.

이 프로그램이 정말 안전한가요?

네, 안전합니다. ORDERMASTER는 GitHub에 소스가 공개되어 있으며, AUTOMASTER(사업자번호: 698-54-00931)에서 직접 개발/배포합니다. GitHub 저장소에서 직접 확인하실 수 있습니다.

관리자 권한이 필요한가요?

아니요. ORDERMASTER는 사용자 폴더에 설치되며 관리자 권한이 필요하지 않습니다. UAC(사용자 계정 컨트롤) 알림이 뜨지 않습니다.

설치 후 어디에 저장되나요?

C:\Program Files\ORDERMASTER\ 경로에 설치됩니다. 제거 시에는 제어판 → 프로그램 추가/제거에서 삭제하실 수 있습니다.
